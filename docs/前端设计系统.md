# 前端设计系统

风格定位：**情报终端** —— 中性石墨灰 + 单一青绿强调色，信息密度高、克制精准；深浅主题同等打磨。

## 1. 令牌（唯一来源）

所有颜色、字体、圆角定义在 `frontend/src/theme/tokens.ts`：

```
tokens.ts ──┬─ applyCssVariables()  →  <html> 上的 --c-* / --font-* / --radius-* 变量
            └─ buildAntdTheme()     →  antd ConfigProvider 主题
```

`ThemeProvider` 切换主题时同时更新两者，**不要在组件里写死颜色值**。

| 用途 | CSS 变量 | 说明 |
| --- | --- | --- |
| 背景层级 | `--c-bg` < `--c-bg-subtle` < `--c-surface` < `--c-elevated` | 页面 / 侧栏 / 面板 / 浮层 |
| 交互态 | `--c-hover`、`--c-active` | 悬停、选中背景 |
| 边框 | `--c-border`、`--c-border-strong` | 分割线 / 控件边框 |
| 文字 | `--c-text`、`--c-text-secondary`、`--c-text-tertiary`、`--c-text-disabled` | |
| 强调 | `--c-accent`、`--c-accent-soft`、`--c-accent-border`、`--c-accent-text`、`--c-accent-contrast` | 强调色上的文字用 `accent-contrast` |
| 语义 | `--c-success/warning/danger/info` 及 `-soft` | 重要度：高=danger，中=warning，低=中性 |
| 图表 | `--c-chart-1` … `--c-chart-5` | 可直接用于 SVG `fill`/`stroke` |
| 阴影 | `--c-shadow-sm/md/lg` | |
| 字体 | `--font-sans`、`--font-mono` | 数字、时间、计数一律 mono |

在 TS 中：

```ts
import { getThemeColor, token } from '@/utils/theme';
style={{ color: token('textSecondary'), borderColor: token('border') }}
getThemeColor(theme, 'primary')   // 兼容旧接口，返回 var(--c-accent)
getThemeHex(theme, 'primary')     // 仅 canvas 等无法用 CSS 变量时使用
```

## 2. 布局

| 端 | 结构 |
| --- | --- |
| PC（≥768px） | 左侧可折叠侧栏 `AppSidebar` + 顶栏（页面标题 + `CommandSearch`）+ 内容区 `.app-page`（最大宽 1480，内边距 24/28） |
| 手机 | 吸顶 `MobileHeader`（标题 + 搜索）+ 悬浮胶囊底栏 `MobileBottomNav` + 「更多」底部面板 |

页面切换同步到 URL：`/?tab=summary`。桌面快捷键：`1-6` 切换页面、`[` 折叠侧栏、`Ctrl/⌘+K` 搜索、资讯页 `J/K` 切换文章。

资讯页为分栏阅读：左列表（按日期分组、重要度圆点、已读变灰）+ 右 `ArticleReader`；手机端点击进入全屏阅读页。

## 3. 全局样式原语（`App.css`）

| 类名 | 用途 |
| --- | --- |
| `.page-header` / `__title` / `__desc` | 页内标题区 |
| `.panel` / `__head` / `__title` / `__body` | 通用面板（替代厚重 Card） |
| `.metric` / `__label` / `__value` / `__foot` | 指标卡，数值 mono |
| `.chip`（`--accent/--danger/--warning/--outline`） | 紧凑标签 |
| `.dot`（`--high/--medium/--low/--live`） | 状态圆点 |
| `.eyebrow` | 小号大写 mono 分组标签 |
| `.kbd` | 快捷键提示 |
| `.icon-btn`（`--active`） | 无边框图标按钮 |
| `.prose`（`--compact`） | Markdown 长文排版；用 `<Markdown>` 组件（`@/utils/markdown`） |
| `.mono`、`.u-muted`、`.u-secondary`、`.u-accent` | 文字工具类 |

页面专属样式放在 `src/styles/pages/<页面>.css` 并在组件中引入，不要再往 `App.css` 堆页面样式。

## 4. 规则

- 颜色只用令牌；不写 `#xxxxxx`、`rgba(...)` 字面量（图表数据色用 `--c-chart-*`）。
- 不写 `!important` 去覆盖 antd 主题；需要调整时改 `buildAntdTheme()` 的 token / components。
- 圆角：控件 8、面板 12、手机卡片 14、底部面板 20。
- 间距以 4 为基数；面板内边距 16–20。
- 数字、日期、计数使用 `--font-mono` + `tabular-nums`。
- 动效短而克制：120–260ms，`cubic-bezier(0.2, 0, 0, 1)`；尊重 `prefers-reduced-motion`。
- 手机端：触控目标 ≥ 38px，底部留出 `--m-tabbar-offset`，注意 `env(safe-area-inset-*)`。
